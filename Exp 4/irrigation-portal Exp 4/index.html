Experiment 4: JavaScript Advisory & Analytics Hub

This module implements all client-side JavaScript logic for the Smart Irrigation Advisory System for Sugarcane Crop (KJS-AGR-01), extending the HTML5 layout (Exp 1) and CSS3 styling (Exp 2).

Task 1: Moisture & Water Calculator

Accepts soil moisture, calculates deficit, and displays water requirement status using alert() and document.write().
